# MacroTracker 🍽️

A sleek, responsive web app for tracking daily meals and macronutrient intake in real-time.

## Try it Out!

https://ahmadyahya-05.github.io/Macro-Tracker/

## Features

- 🎯 Set personalized daily goals for calories, protein, carbs, and fats.
- 🍔 Add meals with macro data and see progress through animated circular charts.
- 📊 Real-time macro summary table with add/delete functionality.

## Tech Stack

- **React.js** (with Hooks)
- **Tailwind CSS** for styling
- **GitHub Pages** for deployment

## How to Run

```bash
npm install
npm start
